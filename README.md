# 온담 · Silver Care

## 오늘도, 당신 곁에.

온담은 어르신과 보호자를 위한 **한국어 AI 생활·건강·복지 안내 서비스**입니다.
일상에서 궁금한 일을 글이나 말로 물어보고, 관련 자료와 문의 경로를 살펴볼 수 있습니다.
어르신이 자신의 이야기를 직접 묻고 선택할 수 있도록 큰 글씨와 단순한 대화 화면을 제공합니다.

**[온담 시작하기](https://ondam-e4b60458.koreacentral.cloudapp.azure.com/)**
· [이용 가이드](docs/user-guide.md)
· [소스 저장소](https://github.com/YOONPYOGitHub/silver-care)

> 온담은 의료진이나 복지 담당자를 대신하지 않습니다. 진단·처방·지원 자격을 확정하지 않으며,
> 응급 상황에는 답변을 기다리지 말고 **119에 직접 전화**해 주세요.

## 온담으로 할 수 있는 일

| 필요한 도움 | 이용 예시 |
| --- | --- |
| 생활·건강 정보 살펴보기 | “건강하게 지내려면 오늘 무엇부터 해보면 좋을까요?” |
| 복지·돌봄 문의 경로 찾기 | “부모님 장기요양 서비스를 알아보고 있어요. 어디에 문의하면 좋을까요?” |
| 마음 나누기 | “가족을 돌보느라 마음이 지쳐요. 잠시 이야기해도 될까요?” |
| 답변의 출처 확인하기 | 답변 아래 출처와 공식 건강정보를 열어 원문·기관 안내 확인 |
| 글 대신 말로 대화하기 | 마이크로 질문하고 음성 답변을 들으며 같은 대화 이어가기 |

마음 나누기는 일상 대화 기능이며 전문 심리상담·위기 모니터링 서비스가 아닙니다.
건강정보와 지원 제도는 개인 상황·지역·시점에 따라 달라질 수 있으므로 의료진이나 담당 기관에 확인하세요.

## 이용 시작하기

1. **서비스에 접속합니다.** 별도 회원가입이나 앱 설치 없이 브라우저에서 이용합니다.
2. **궁금한 일을 적고 보내기를 누릅니다.** 주제 카드를 누르면 예시 질문이 바로 전송됩니다.
3. **답변과 출처를 함께 읽습니다.** 원문과 적용 조건을 확인하고, 필요한 경우 추가로 질문합니다.
4. **음성이 편하다면 ‘말로 대화’를 선택합니다.** 마이크 권한을 허용한 뒤 말하면
   발화 종료 후 질문이 자동 전송됩니다. ‘잠시 멈춤’이나 ‘글로 대화’로 마이크를 끌 수 있습니다.

휴대전화와 PC에서 이용할 수 있으며, 음성 지원 여부는 브라우저·마이크 권한에 따라 달라집니다.
[이용 가이드](docs/user-guide.md)에서 큰 글씨, 음성 조작, 출처 확인, 연결 문제 해결 방법을 확인하세요.

## 안심하고 이용하려면

- **개인정보를 적거나 말하지 마세요.** 이름·연락처·주민등록번호·상세 주소를 보내지 않습니다.
  개인정보 패턴 처리 기능이 있지만 완전한 익명화를 보장하지는 않습니다.
- **대화는 현재 탭에서만 이어집니다.** 새로고침이나 ‘새로운 대화’로 초기화되며 복원 기능은 없습니다.
  앱은 글과 음성을 상담 이력으로 저장하지 않지만, 답변 처리에 필요한 질문·최근 대화와 음성은
  외부 Azure 서비스로 전송됩니다. 외부 제공자의 처리·보관 정책까지 무저장을 보장하는 것은 아닙니다.
- **출처가 있어도 오류가 있을 수 있습니다.** 진료·복약 변경·검사 시행·지원금·자격 결정에 단독으로 사용하지 마세요.
- **자동 신고·실시간 돌봄은 제공하지 않습니다.** 119 버튼은 전화 앱 또는 안내창을 열며 자동 신고나 위치 전송을 하지 않습니다.

## 제공 범위

온담은 자료 검색과 선택형 음성을 제공하는 온라인 서비스입니다.
현재는 개인 계정·장기 기억·상담 기록 복원·의료기관 예약·복지 신청 대행을 제공하지 않습니다.
인터넷 연결과 외부 모델·검색·음성 서비스가 필요하며 휴대폰에서 오프라인으로 실행되는 앱이 아닙니다.

응답 시간과 가용성을 보장하는 SLA 또는 고가용성 구성을 제공하지 않습니다.
요청 크기·빈도·동시 처리 제한이 있으며, 연결 오류는 화면에 표시합니다.
품질 평가는 전문가 검토 전 자동 평가를 포함하고 **임상적 정확성·안전성 인증이 아닙니다.**
WHO·한국 기본소생술 지침 등 일부 자료는 **비상업적 이용 조건**으로 사용합니다.
유료화나 상업적 재사용 전에는 자료별 권리를 별도로 검토해야 합니다.

## 답변은 어떻게 준비하나요?

| 경로 | 자료 | 사용 방식 |
| --- | --- | --- |
| 임베딩 검색 | AI Hub 의학 원천, 보건복지부 매뉴얼, MedlinePlus, WHO ICOPE, VA 욕창 지침, FDA 약물 자료, 기관·서비스 안내 | 관련 문서를 검색해 사실 근거로 전달·인용 |
| 임베딩 검색 | 복지로 중앙부처·장기요양기관 검색 API의 수집 응답 | 수집 시 문서화·임베딩한 스냅샷을 검색. 채팅 중 API를 호출하지 않음 |
| 임베딩 검색 | AI Hub 감성 대화·의학 QA | 대화·질문 참고 사례. 사실 근거로 인용하지 않음 |
| 실행 시 API 조회 | 질병관리청 건강정보 21개 주제 | 질문에 맞는 본문을 조회·발췌해 답변 근거로 전달·인용 |
| 평가 전용 | QA·대화 holdout, AI Hub 어르신 음성 표본 | 온라인 검색·답변 근거로 사용하지 않음 |

기본 서비스는 질문에 관련된 자료를 찾아 답변에 참고하고, 인용한 자료를 답변 아래에 표시합니다.
대화·QA 사례는 말투와 질문 의도 참고용이며 사실 근거로 인용하지 않습니다.
복지·기관 API 자료는 수집 시점의 스냅샷으로, 질문할 때마다 최신 신청 상태를 조회하는 것은 아닙니다.
질병관리청에는 허용된 콘텐츠 ID와 인증키만 보내며 질문·대화 이력은 보내지 않습니다.
자료의 범위·수량·이용조건과 답변 처리 방식은 [RAG·API 문서](docs/rag.md)에 있습니다.

## 운영·개발 구성

사용자 화면과 대화 기능은 공통으로 유지하고 모델·검색 연결은 실행 프로필로 분리합니다.
기본 접속 주소는 GPT + Azure Search 구성입니다. Qwen + Azure Search, Qwen + 자체 검색,
검색 없는 모델 단독 구성도 별도 경로에서 운영하며, 모델 단독에는 자료 검색·공식 건강정보가 없습니다.
전체 경로·기능 차이·자원 분리는 [실행 구성](docs/architecture.md#서비스-실행-구성)을 참고하세요.
사용자에게 서비스 이용 전에 모델이나 검색 공급자를 선택하도록 요구하지 않습니다.

## 로컬 실행

Python 3.12+, [uv](https://docs.astral.sh/uv/), 모델·검색 접근에 필요한 Azure 자격이 필요하다.
[환경변수 예시](.env.example)를 참고하되 실제 환경 파일을 덮어쓰지 않는다.
예시 파일의 연결값은 비어 있으므로 실제 endpoint·배포명·리소스·키를 비공개 `.env`에 설정한다.

```bash
uv sync --group dev
az login
APP_ENV=development PUBLIC_ORIGIN=http://127.0.0.1:8000 TRUSTED_PROXY=false \
uv run uvicorn silvercare.app:create_app --factory --host 127.0.0.1 --port 8000
```

명령은 설정된 기능만 활성화한다. 운영 하이브리드 검색 설정을 로컬에서 사용하려면
[연결 실행 절차](docs/operations.md)를 따른다. `PUBLIC_ORIGIN`은 브라우저 주소와 같아야 한다.

## 검증

```bash
uv run pytest -q
uv run ruff check silvercare tests
uv run mypy
node --check silvercare/static/app.js
uv run --project evaluation pytest -q evaluation/tests
uv run --directory evaluation ruff check ondam_eval tests
uv run --directory evaluation mypy
```

프론트엔드 회귀 테스트와 JavaScript 문법 검사에는 Node.js가 필요하다.
Node.js가 없으면 해당 pytest가 건너뛰어질 수 있으므로 전체 검증 환경에서 설치 여부를 확인한다.
검색 적중률, 실제 모델의 출처 인용, 음성 인식 측정은 별도 평가다.
명령·결과 위치·표본 한계는 [운영 가이드](docs/operations.md)를 참고한다.
실제 모델·검색·음성 호출에는 사용량 비용이 발생할 수 있다.

## 운영 경계

앱은 AKS에서 공개 HTTPS로 제공하며 모델·검색·음성에는 Workload Identity로 접근한다.
질병관리청 키와 선택적 평가 추적 토큰은 각각 전용 Kubernetes Secret으로 주입한다.
Azure API 키·원본·정제본은 이미지에 넣지 않는다.
Azure 리소스가 한국에 있어도 `GlobalStandard` 모델의 국내 추론을 보장하지는 않는다.
단일 노드·앱·엣지·검색 replica 구성은 고가용성 구성이 아니다.

[.gitignore](.gitignore)는 인증정보·원본·처리 결과·런타임 상태를 제외하고,
[.dockerignore](.dockerignore)는 빌드 입력을 애플리케이션과 의존성 파일로 제한한다.
제공처 HWP·Word 가이드는 로컬 참고용이며 Git에 포함하지 않는다.
업로드 대상과 추적 중인 비밀값의 주의사항은 [Git 확인 절차](docs/operations.md#8-git-업로드-전-확인)에 있다.
문서 변경은 서비스 재배포나 데이터 재적재를 요구하지 않는다.
