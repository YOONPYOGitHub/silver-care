# 원본 데이터 구조·검증

AI Hub 원본 파일 재확인일: 2026-11-11. 노령층 복지서비스 안내서 확인일: 2026-11-13.
이 문서는 [catalog.json](../data/catalog.json)에 등록한 실제 파일의 구조·통계·출처 한계를 설명한다.
운영 검색 문서 수와 답변 처리 방식은 [RAG·API](rag.md), 실행 명령은 [운영 절차](operations.md)에 있다.
원본 레코드 수와 정제·분할·평가 분리 후의 검색 청크 수를 혼동하지 않는다.

## 1. 확인한 AI Hub 파일

| 데이터셋 | 파일 ID | 역할 | 원본 레코드 |
| --- | --- | --- | ---: |
| 전문 의학지식 71874 | 556339 | 학회 가이드라인 원천 | 1,298 |
| 필수의료 의학지식 71875 | 556377 | 온라인 의료정보 원천 | 2,034 |
| 전문 의학지식 71874 | 556353 | 예방의학 QA | 595 |
| 필수의료 의학지식 71875 | 556388 | 내과 QA | 1,248 |
| 감성 대화 86 | 66048 | 대화 JSON | 6,640 |

전체 데이터셋을 전부 분석했다는 의미는 아니다. 파일의 역할은 catalog로,
원본별 크기·SHA256은 `data/raw/aihub/registry.json`으로 추적한다.

공식 다운로드는 TAR 안에 ZIP 또는 ZIP part를 포함할 수 있다.
의학 파일의 동일 이름·내용 ZIP part 중복은 내용 비교 후에만 제거한다.
원본 레코드 중복과 아카이브 part 중복은 다른 문제다.
TAR 포장 메타데이터가 다르면 내부 자료가 같아도 전체 파일 hash는 다를 수 있다.

## 2. 의학 원천

실제 필드는 다음과 같다.

```text
c_id / domain / source / source_spec / creation_year / content
```

| 항목 | 71874 / 556339 | 71875 / 556377 |
| --- | ---: | ---: |
| 레코드 | 1,298 | 2,034 |
| 정규화 본문 최소 길이 | 133자 | 41자 |
| 정규화 본문 중앙 길이 | 588자 | 219자 |
| 정규화 본문 최대 길이 | 5,010자 | 3,576자 |
| 정규화 후 파일 내 완전 중복 | 0 | 0 |

길이는 [normalize](../silvercare/privacy.py)로 처리한 `content` 기준이다.
완전 중복이 없다고 의미상 중복이나 가이드라인 충돌까지 없다고 보장하지 않는다.

- 학회 원천의 `source_spec`에는 여러 학회 표기가 있다.
- 온라인 원천의 출처 표기는 `ADA` 1,995개, `wikidoc` 39개다.
- 두 원천에는 원문 URL 필드가 없다. 출처 표기는 실제 원문 페이지를 확인했다는 뜻이 아니다.
- `creation_year`의 문자열 `"null"`은 연도로 해석하지 않는다. 기재 연도를 최신 임상 검증일로 바꾸지 않는다.
- 의학 원천의 숫자 `domain`을 QA의 진료과 코드와 같은 의미라고 가정하지 않는다.
- 출처 추적에는 dataset ID·file ID·`c_id`·출처 표기를 함께 사용한다.

임상적 표현이나 의학 키워드가 있다는 이유로 일괄 제외하지 않는다.
실제 정제·분류·본문 길이 기준은 [data.py](../silvercare/data.py)에 있다.
자동 정리본을 임상의가 승인한 지식으로 표시하지 않는다.

## 3. 의학 QA

```text
qa_id / domain / q_type / question / answer
```

| 파일 | 객관식(1) | 단답형(2) | 서술형(3) | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 예방의학 556353 | 536 | 27 | 32 | 595 |
| 내과 556388 | 995 | 105 | 148 | 1,248 |

정답 필드는 정답 번호·선택지·단답·서술 등 서로 다른 형태를 담는다.
“틀린 설명”을 고르는 문제의 정답 문장은 사실이 아닐 수 있다.
원천 문서를 직접 가리키는 필드가 없으므로 비슷한 문서를 검색했다고 정답 근거가 검증되는 것은 아니다.

QA는 질문·선택지·라벨 정답·해석 유형을 보존한 사례다.
모델에 전달하는 범위와 평가 분할은 [사례 인덱스 설명](rag.md#사례-인덱스-silvercare-cases-v5-6762개)을 따른다.
원본 파일명이 Validation이라는 이유만으로 전부 평가 전용이라고 해석하지 않는다.

## 4. 감성 대화

```text
profile.persona / profile.emotion
profile.persona.human
talk.id / talk.content
talk.content: HS01, SS01, HS02, SS02, HS03, SS03
```

6,640개 레코드의 원본 연령 코드 분포다.

| 코드 | 연령 구분 | 원본 대화 |
| --- | --- | ---: |
| A01 | 청소년 | 1,437 |
| A02 | 청년 | 1,572 |
| A03 | 중년 | 1,578 |
| A04 | 노년 | 2,053 |

연령 코드 의미는 AI Hub 86 공식 설명서 10쪽으로 확인한다.
설명서 hash와 위치는 [검증 근거](operations.md#검증-결과와-한계)에 있다.
이 표는 holdout 분리 전이며 [검색 대상 연령 분포](rag.md#대화-연령-정보)와 다르다.

사용자·응답 예시의 역할을 구분하며, 대화 속 건강 조언이나 감정 라벨을 의학적 사실·진단으로 쓰지 않는다.
원본 화자 연령과 실제 앱 이용자의 나이·가족관계는 별개의 정보다.
원본 대화·개인정보·인증키·서명된 다운로드 URL을 이 문서에 복제하지 않는다.

## 5. 복지로 2026 노령층 복지서비스 PDF

공식 PDF는 2,866,340바이트·48쪽이며 인쇄일은 2026-06-30이다.
원본 SHA256은 `74cde38350d49bb767c2bb217022a3ff17e1021cec36966534963e9c4e269bd5`다.
보건복지부 발간 게시일 2026-07-19와 인쇄일은 개정일·현재 수급조건 확인일이 아니다.

| 구조 | 실제 범위 | 처리 |
| --- | --- | --- |
| 목차 | 4~5쪽, 01~35 사업 | 사업 ID·제목·시작 쪽을 검증하는 용도 |
| 사업 안내 | 6~46쪽 | 사업별 원문 범위, 대상·내용·방법·문의 구분 |
| 요금감면 제도 | 11~12쪽 | 검증한 오른쪽 신청·문의 열만 추출 |
| 발행 정보 | 47쪽 | 기관·인쇄일·발간등록번호 검증, 본문 제외 |
| 표·도식·이미지·FAQ | 여러 쪽 | 대상 7개·내용 19개 절의 표/도식, 이미지·FAQ 제외 |

기초연금 금액표는 단독/부부 열과 병합 셀의 관계가 일반 PDF 추출에서 소실되는 것을 확인했다.
일부 표 탐지 결과도 셀 누락·페이지 테두리 오인식이 있어, 자동 표 복원을 성공한 것으로 처리하지 않는다.
검토한 원본에 한해 절 단위 제외와 요금감면 문의 열 좌표를 고정하며 원본 변경은 hash 검증에서 거부한다.
일반 문단은 보존하고 35개 사업을 35개 검색 청크로 구성한다. 이 중 34개는 본인용, 1개는 사업주용이다.

책 자체 제작 허용은 [발간 게시물 본문](https://www.mohw.go.kr/board.es?mid=a10411010300&bid=0019&act=view&list_no=1491341)에서 확인하며,
별도 이용 제한이 있는 이미지는 추출·발행하지 않는다. 운영 역할·권한의 한계는 [RAG 안내서 설명](rag.md#2026-노령층-복지서비스-안내서)을 따른다.
