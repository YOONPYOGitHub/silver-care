# 온담 이용 가이드

온담은 어르신과 보호자가 생활·건강·복지 정보를 살펴보고 일상의 이야기를 나누는 한국어 AI 서비스입니다.
이 가이드는 [기본 서비스](https://ondam-e4b60458.koreacentral.cloudapp.azure.com/)의 이용 방법입니다.
별도 모델 단독 구성은 자료 검색·출처·공식 건강정보 기능을 제공하지 않습니다.

> 의식이 없거나 숨쉬기 어렵고 갑작스러운 심한 가슴 통증·마비가 있다면,
> 채팅 답변을 기다리지 말고 **119에 직접 전화**해 주세요. 온담은 자동 신고나 위치 전송을 하지 않습니다.

## 1. 처음 이용하기

1. 휴대전화나 PC의 브라우저에서 온담에 접속합니다. 회원가입이나 별도 앱 설치는 필요하지 않습니다.
2. 기본 대화 방식은 **글로 대화**입니다. 아래 입력창에 질문을 적고 보내기를 누릅니다.
3. 어떤 질문을 할지 고민된다면 **생활 · 건강**, **복지 · 지원**, **마음 나누기** 중 하나를 선택합니다.
   주제 카드는 입력 예시만 채우는 것이 아니라 **질문을 바로 전송**합니다.
4. 가족을 위한 질문은 **가족을 돌보고 계신가요?**를 펼쳐 선택할 수도 있습니다.

누구에 관한 질문인지 함께 적으면 도움이 됩니다. 예를 들어 “제 이야기예요”,
“부모님 돌봄을 알아보고 있어요”처럼 설명하되 이름·연락처·주민등록번호·상세 주소는 넣지 마세요.

## 2. 글로 대화하기

- 한 번에 최대 **2,000자**까지 보낼 수 있습니다.
- PC에서는 **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿉니다.
- 질문을 나누어 보내거나 “좀 더 쉽게”, “단계별로 설명해 주세요”처럼 이어서 물을 수 있습니다.
- **돌봄 대화**는 최근 메시지로 이동합니다. 이전 답변을 읽는 중 새 답변이 오면
  **새 답변 보기**를 눌러 이동할 수 있습니다.
- **새로운 대화**는 현재 대화를 초기화합니다. 새로고침해도 대화가 사라지며 복원 기능은 없습니다.

현재 탭의 대화는 화면에 남아 있어도, 답변 요청에는 최근 12개 이전 메시지만 전달됩니다.
오래전에 말한 내용까지 기억한다고 가정하지 말고 중요한 맥락은 다시 알려주세요.

## 3. 말로 대화하기

음성 대화에는 마이크와 이를 지원하는 브라우저가 필요합니다. 공용 기기에서는 주변에 들릴 수 있는
정보를 말하지 않도록 주의하세요. 음성 인식 결과도 질문으로 전송됩니다.

1. 화면 아래 **말로 대화**를 선택하고 마이크 권한을 허용합니다.
2. 듣는 상태에서 편하게 말합니다. 마이크 표시와 음량 막대는 입력 여부를 알려주며 인식 정확도를 뜻하지 않습니다.
3. 말을 마치고 **약 3초** 쉬면 자동으로 전송됩니다. 먼저 보내려면 **말 마침**을 누릅니다.
4. 인식된 질문과 답변이 대화 목록에 표시되고 답변을 소리로 읽습니다.
5. 재생이 끝나면 다음 말을 듣습니다. 답변 재생 중에는 녹음하지 않습니다.

| 하고 싶은 일 | 조작 |
| --- | --- |
| 마이크와 음성 대화를 멈추기 | **잠시 멈춤** 또는 **글로 대화** |
| 답변을 끊고 다시 말하기 | 답변 준비·재생 중 **답변 멈추고 말하기** |
| 멈춘 대화 이어가기 | **대화 시작** |
| 글로 받은 답변 듣기 | 해당 답변의 **이 답변 듣기** |

- 한 번의 녹음은 **최대 2분·4MB**이며 전체 대화 시간 제한이 아닙니다.
- 입력 없이 약 30초가 지나면 일시정지합니다.
- 화면 설정·이용 안내·119 안내를 열거나 다른 화면으로 벗어나면 음성을 멈춥니다.
  돌아와도 자동으로 마이크를 켜지 않으며 **대화 시작**으로 재개합니다.
- 인식이 잘못됐다면 **글로 대화**로 전환해 바로잡는 질문을 보내세요.
  음성은 전송 전에 반드시 확인받는 받아쓰기 방식이 아니라 자동 전송 방식입니다.
- 화면의 서식 기호·인용 번호·별도 출처 목록은 음성에서 생략할 수 있습니다.
  근거는 화면에서 확인하고 주의사항·숫자·단위도 함께 읽어주세요.

## 4. 출처와 공식 건강정보 확인하기

답변 아래 출처를 열어 원문과 적용 조건을 확인하세요. 모든 답변에 출처가 있는 것은 아닙니다.
출처가 없거나 확인이 필요하다고 안내되면 검증된 사실로 단정하지 마세요.

**함께 알아보기**에서 공식 건강정보 목록을 펼치고 주제를 골라 **원문 보기**로 확인할 수 있습니다.
이는 질병관리청이 제공하는 허용된 주제의 본문으로, 개인의 검사 결과나 진료 기록을 조회하는 기능이 아닙니다.
화면의 조회 시각이 자료의 개정일을 뜻하지는 않습니다.
자료별 출처·가공·이용조건은 **이용 안내 → 자료 출처·이용조건**에서도 확인할 수 있습니다.

복지 금액·대상·서류·신청 기간은 지역과 시점에 따라 달라질 수 있습니다.
온담은 신청 대행이나 자격 심사를 하지 않으므로 최종 내용은 담당 기관에서 확인하세요.

## 5. 읽기 편하게 설정하기

- PC 왼쪽 메뉴나 휴대전화 상단의 **화면 설정**에서 글자 크기를 고릅니다.
- 입력창과 대화 방식 버튼은 화면 아래에 남아 있으며, 대화 내용은 위쪽에서 스크롤해 읽습니다.
- 답변이 길면 본문부터 읽고 아래로 내려 출처와 추가 자료를 확인합니다.
- 설정창을 열어도 대화 내용은 유지됩니다. 음성만 일시정지하므로 필요할 때 다시 시작하세요.

## 6. 연결이 원활하지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 답변이 늦어요 | 자료 조회와 외부 연결에 시간이 걸릴 수 있습니다. 연속 전송을 피하고 오류가 표시되면 안내에 따라 다시 시도하세요. 응급 상황에는 기다리지 마세요. |
| 잠시 후 다시 시도하라고 해요 | 요청 제한 또는 일시적인 연결 문제일 수 있습니다. 잠시 기다린 뒤 시도하세요. |
| 마이크가 켜지지 않아요 | 브라우저·기기의 마이크 권한과 사용 가능 여부를 확인하세요. 이용이 어렵다면 글로 대화를 사용하세요. |
| 답변 소리가 들리지 않아요 | 기기의 음량·음소거·오디오 재생 제한을 확인하고 화면의 재생 안내를 따르세요. |
| 공식 자료가 열리지 않아요 | 외부 정보 제공처의 연결 문제일 수 있습니다. 확인되지 않은 내용을 대신 확정하지 말고 나중에 다시 확인하세요. |
| 이전 대화가 사라졌어요 | 새로고침·새 대화로 초기화된 기록은 복원할 수 없습니다. |

새로고침은 대화를 지우므로 연결 문제를 확인할 때 이 점을 유의하세요.
온담은 정해진 시간 안의 응답이나 상시 가용성을 보장하는 긴급 대응 서비스가 아닙니다.

## 7. 개인정보와 이용 범위

앱은 글과 음성을 서버의 상담 이력으로 저장하지 않습니다.
다만 답변을 위해 질문·최근 대화·관련 자료를 Azure 모델로 보내고, 음성 모드에서는 발화를 Azure 음성 인식으로
전송하며 답변 텍스트를 음성 합성으로 보냅니다. 외부 제공자의 처리·보관 정책까지 무저장을 보장하지 않습니다.
개인정보 패턴을 줄이는 처리가 완전한 익명화나 외부 전송 차단을 뜻하지는 않습니다.

온담은 의료·심리 전문 상담, 진단·처방, 약의 용량 변경, 응급 모니터링을 제공하지 않습니다.
AI 답변과 출처에 오류나 오래된 정보가 있을 수 있으므로 중요한 판단은 의료진·약사·담당 기관에 확인하세요.

현재 기능 범위는 [서비스 소개](../README.md), 자료 처리와 기술적 한계는 [데이터·답변 처리](rag.md)를 참고하세요.
